# Skills 页面卡片高度修复设计

## 问题

Skills 页面使用 `BoxLayout.Y_AXIS` 排列 Skill 卡片。卡片在加入复选框、详情文本和操作按钮之前，便读取空面板的首选高度并将其设置为最大高度。空面板此时只计算边框内边距，高度约为 17px；加入多行内容后实际首选高度约为 81px，但最大高度没有更新，最终导致描述、触发词和所需工具等内容重叠或被裁切。

## 修复范围

- 仅调整 Skill 卡片最大高度的计算时机。
- 卡片完成所有子组件组装后，再使用最终首选高度限制其最大高度。
- 保留现有标题栏、滚动容器、卡片内容、颜色、间距和交互。
- 不在本次修复中处理未确认的 HTML 转义或超长文本换行问题。

## 验证

- 增加回归测试，构造包含描述、触发词和所需工具的多行 Skill 卡片。
- 测试断言卡片最大高度不小于组装完成后的首选高度，并先确认该测试在现有实现上失败。
- 修复后重新运行回归测试、完整测试与插件构建。
- 在 IDE 页面中确认 Skill 卡片按内容自然增高，没有重叠或裁切。

## 风险

修复不改变 Skill 数据、启用状态或交互逻辑。唯一布局影响是卡片恢复到内容所需的自然高度，因此风险集中在列表纵向尺寸；滚动容器会继续处理超出视口的内容。
